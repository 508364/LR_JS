## 完成内容

### 1. Promise 系统 (`src/lr_promise.h/c`)
- **Promise 构造函数**: `new Promise(executor)`，支持 executor(resolve, reject) 模式
- **链式调用**: `.then(onFulfilled, onRejected)` 返回新 Promise
- **错误处理**: `.catch(onRejected)` 委托给 `.then(null, onRejected)`
- **最终处理**: `.finally(callback)` 使用 wrapper 函数确保 finally 执行
- **静态方法**:
  - `Promise.resolve(value)` — 返回已决议的 Promise
  - `Promise.reject(reason)` — 返回已拒绝的 Promise
  - `Promise.all(iterable)` — 所有成功或第一个失败
  - `Promise.race(iterable)` — 第一个完成的 Promise
  - `Promise.allSettled(iterable)` — 等待所有完成（无论成败）
  - `Promise.any(iterable)` — 第一个成功的 Promise
- **微任务调度**: 使用 `lr_enqueue_job()` 调度 Promise 回调
- **内部状态**: 通过 `lr_set_opaque`/`lr_get_opaque` 附加到 JS 对象

### 2. 引擎集成
