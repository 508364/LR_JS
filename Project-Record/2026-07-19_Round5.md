## 概述

实现三个功能：
1. `.lrfile` 字节码缓存机制 — 将编译后的 JS 字节码持久化到磁盘
2. 沙箱独立日志系统 — 每个沙箱独立的 UUID 标识日志文件
3. API 调用文档 — 支持 Windows/Linux/macOS/BSD/移动端

## 新增文件

### `src/lr_bytecode.h` / `src/lr_bytecode.c`

**字节码缓存 (.lrfile)**：
- 使用 FNV-1a 64-bit 哈希作为缓存键
- 缓存文件格式：magic("LRBC") + version + flags + hash + mtime + src_size + bytecode
- 支持绝对和相对缓存目录
- 缓存目录为 NULL 时功能禁用
- 自动检测源文件修改（mtime + hash 双重校验）
- 内存 LRU 缓存（最多 256 条目）
- 线程安全（pthread_mutex）

**统计**：
- 命中/未命中/存储/失效计数
- 存储/加载字节数
- 命中率计算

### `src/lr_sandbox_log.h` / `src/lr_sandbox_log.c`

**沙箱日志系统**：
- 每个沙箱自动生成 UUID v4
- 日志文件命名：`{date}-{run_count}-{uuid}.log`
- 独立的日志目录（可配置绝对/相对路径）
- 日志目录为 NULL 时功能禁用
- 独立运行：专用 flush 线程（默认 500ms 间隔）
- 非阻塞写入：缓冲在内存中，异步刷新到磁盘
- 每日自动轮转：日期变化时创建新文件
- 运行计数：追踪当日沙箱执行次数

**日志级别**：ERROR, WARN, INFO, DEBUG, TRACE

**日志格式**：
```
[2026-07-19 14:30:25.123456] [INFO ] [eval:1] Sandbox created: my-sandbox (uuid=...)
[2026-07-19 14:30:25.234567] [INFO ] [eval:1] Eval started: <sandbox>
[2026-07-19 14:30:25.245678] [INFO ] [eval:1] Eval completed in 11.11 ms
```

## 关键设计决策

1. **FNV-1a 哈希**：选择 64-bit FNV-1a 替代 SHA-256，因为：
   - 字节码缓存不需要加密安全性
   - FNV-1a 计算速度极快
   - 64-bit 碰撞概率足够低用于缓存

2. **双重缓存失效**：同时检查 mtime 和内容哈希，确保：
   - 文件修改后缓存自动失效（mtime）
   - 内容替换后缓存自动失效（hash）

3. **异步日志写入**：日志写入是非阻塞的：
   - 缓冲在内存中
   - 专用 flush 线程定期写入
   - 避免阻塞沙箱执行

4. **跨平台 UUID**：优先使用加密随机源，回退到 PRNG：
   - Windows: CryptGenRandom
   - Unix: /dev/urandom
   - 回退: 时间 + PID
