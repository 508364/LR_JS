## 修复内容

### 1. C 函数原型链修复（`Uint8Array.constructor === Function`）

**问题**：`Uint8Array.constructor === Function` 返回 `false`。C 函数（CFUNCTION 对象）没有设置原型链，无法访问 `Function.prototype` 上的 `constructor`、`call`、`apply`、`bind` 等方法。

**根因**：`lr_new_cfunction2` 使用 `lr_object_alloc` 创建对象，`calloc` 将所有字段初始化为零，`proto` 字段为 NULL。原型链从未被设置。

**修复**：在 `lr_new_cfunction2` 中，创建函数对象后检查 `ctx->function_proto` 是否可用，如果可用则设置为原型：

```c
if (ctx->function_proto.tag == LR_TYPE_OBJECT) {
    obj->proto = lr_dup_value(ctx, ctx->function_proto);
}
```

**文件**：[lr_engine.c](file:///workspace/LR_JS/src/engine/lr_engine.c)（第 480-487 行）
