# Round 10 - 替换 QuickJS 引擎为自实现引擎 LR_Engine

**时间**: 2026-07-19 06:00
**主题**: 完全自实现 JS 引擎 —— 替换 QuickJS 依赖，LR_JS 不再引用任何外部 JS 引擎源码

---

## 背景
用户质疑 LR_JS 是否真的完全自实现。此前项目通过 `ENGINE_DIR = ../quickjs` 直接引用外部 QuickJS 引擎源码（`quickjs.c`, `libregexp.c`, `libunicode.c`, `cutils.c`, `quickjs-libc.c`, `dtoa.c`），这些文件位于 `/workspace/quickjs/` 目录下。

用户要求：逻辑思路可以和 QuickJS/V8 一样，但不能直接引用其文件/路径。

## 目标
创建完全自实现的 JS 引擎（`src/engine/`），替换 QuickJS 依赖，使 LR_JS 成为真正的完全自实现项目。

## 完成内容

### 1. 新建 `src/engine/lr_engine.h` — 引擎公共头文件 (~740 行)
- **值系统**：`LRValue` 使用 tagged union 表示 JS 值（undefined, null, bool, int32, float64, string, object, symbol, exception）
- **常量**：`LR_VALUE_UNDEFINED`, `LR_VALUE_NULL`, `LR_VALUE_TRUE`, `LR_VALUE_FALSE`, `LR_VALUE_EXCEPTION`
- **字符串**：`LRString` 结构体，带引用计数和原子化支持
- **对象模型**：`LRObject` 支持 hidden class (shape)、属性哈希表、原型链
- **属性系统**：`LRProperty` 带 getter/setter/accessor 标志
- **Shape（隐藏类）**：`LRShape` 用于快速属性访问
- **C 函数**：`LRCFunction` 和 `LRCFunctionListEntry` 支持原生函数注册
- **字节码函数**：`LRBytecodeFunction` 预留结构
- **Runtime/Context**：`LRRuntime` 和 `LRContext` 生命周期管理
- **类系统**：`LRClass` 支持自定义类
- **模块**：`LRModuleDef` 模块加载器支持
- **Job 队列**：`LRJobEntry` Promise 微任务队列
- **完整兼容宏**：所有 `JS_*` 宏映射到 `lr_*` 函数，保持 LR_JS 层代码不变

### 2. 新建 `src/engine/lr_engine.c` — 引擎核心实现 (~1180 行)
- **内存管理**：`lr_malloc`/`lr_realloc`/`lr_free` 跟踪内存使用
- **字符串操作**：`lr_string_alloc`/`lr_string_free`/`lr_string_dup`/`lr_string_release`
- **对象操作**：`lr_object_alloc`/`lr_object_free`/`lr_object_dup`/`lr_object_release`
- **值创建**：`lr_new_bool`, `lr_new_int32`, `lr_new_float64`, `lr_new_string`, `lr_new_string_len`
- **对象/数组创建**：`lr_new_object`, `lr_new_object_proto`, `lr_new_array`
- **C 函数创建**：`lr_new_cfunction`, `lr_new_cfunction2`
- **值管理**：`lr_dup_value`, `lr_free_value`, `lr_to_cstring`, `lr_free_cstring`
- **类型检查**：`lr_is_*` 系列（undefined, null, bool, number, string, object, array, function, exception, symbol, array_buffer, promise）
- **类型转换**：`lr_to_bool`, `lr_to_int32`, `lr_to_float64`
- **属性访问**：`lr_get_property`, `lr_set_property`, `lr_delete_property`, `lr_define_property_value`
- **属性名枚举**：`lr_get_own_property_names`, `lr_free_property_enum`
- **函数调用**：`lr_call`（支持 CFunction 分发）, `lr_call_constructor`
- **属性列表注册**：`lr_set_property_function_list`（支持 `JS_CFUNC_DEF` 宏）
- **原型链**：`lr_get_prototype`, `lr_set_prototype`
- **全局对象**：`lr_get_global_object`
- **错误处理**：`lr_throw_*` 系列（TypeError, ReferenceError, RangeError, SyntaxError, InternalError）
- **Runtime/Context 生命周期**：`lr_new_runtime`/`lr_free_runtime`/`lr_new_context`/`lr_free_context`
  - Context 链使用 `next_ctx` 字段，避免与 `opaque` 冲突
  - `lr_free_context` 从链表中移除自身，防止 double-free
- **Job 队列**：`lr_is_job_pending`, `lr_execute_pending_job`, `lr_enqueue_job`
- **GC**：`lr_gc_run`（桩），`lr_engine_compute_memory_usage`
- **Atom 表**：`lr_new_atom`/`lr_new_atom_len` 支持字符串原子化（去重）
- **ArrayBuffer**：`lr_new_array_buffer`, `lr_get_array_buffer`, `lr_new_array_buffer_copy`, `lr_get_typed_array_buffer`
- **Promise**：`lr_new_promise_capability`（桩）
- **评估**：`lr_engine_eval`（桩，返回 `LR_VALUE_UNDEFINED`，Lexer/Parser/Compiler/VM 待后续实现）

## 技术要点
- 值使用 struct tagged union 表示（非 NaN-boxing），便于调试
- 对象使用属性哈希表 + Shape 链（hidden class）优化
- 字符串使用原子表去重（interning）
- 引用计数管理生命周期
- Context 链使用 `next_ctx` 字段，不污染 `opaque` 用户数据
- `lr_free_context` 从链表中移除自身，防止 `lr_free_runtime` 重复释放
