# L/R_JS Project - Round 3: 系统内存限制

**时间**: 2026-07-18  
**主题**: 制作运行内存限制，运行内存必须大于等于1G，不然不允许运行

---

## 概述

添加了系统内存检测功能，确保 L/R_JS 运行时有足够的系统可用内存（默认至少 1GB）。

## 代码变更

### 1. 公共头文件 (`include/lr_js.h`)

- 在 `LR_Config` 中添加了两个新字段：
  ```c
  size_t  min_system_memory;   /* minimum system available memory (bytes), 0 = check disabled */
  int     skip_memory_check;   /* 1 = skip the system memory check entirely */
  ```
- 添加了两个公开 API 函数声明：
  ```c
  int     lr_check_system_memory(size_t min_bytes);
  int64_t lr_get_available_memory(void);
  ```

### 2. 运行时 (`src/lr_runtime.c`)

- 添加 `#include <unistd.h>`
- `lr_config_default()` 中设置默认值：
  - `min_system_memory = 1073741824` (1 GB)
  - `skip_memory_check = 0`
- 实现 `lr_get_available_memory()`:
  - Linux: 读取 `/proc/meminfo`，优先使用 `MemAvailable`，回退到 `MemFree + Buffers + Cached`
  - 回退方案: 使用 `sysconf(_SC_AVPHYS_PAGES)` 和 `sysconf(_SC_PAGESIZE)`
- 实现 `lr_check_system_memory()`:
  - 如果无法确定可用内存，允许继续（返回 0）
  - 如果可用内存不足，返回 -1
- 在 `lr_runtime_new()` 开头添加内存检查：
  - 如果未跳过检查且设置了最小内存要求
  - 检查失败时打印 ASCII 画框错误信息并返回 NULL

### 3. CLI (`cli/main.c`)

- 添加 `--min-memory <bytes>` 参数
- 添加 `--no-memory-check` 参数
- 更新帮助文本

## 问题修复

### Segfault (exit 139)
- **问题**: 添加内存检查后，`console.log('Hello')` 出现 segfault
- **原因**: `make` 只重新编译了 `lr_runtime.c` 和 `main.c`，其他依赖 `lr_js.h` 的模块（如 `lr_worker.c`）使用了旧的 struct 布局（没有 `min_system_memory` 和 `skip_memory_check` 字段）
- **修复**: 执行 `make clean && make` 完整重新编译
