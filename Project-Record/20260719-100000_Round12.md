# Round 12 - EGL 自定义渲染器插件机制

**时间**: 2026-07-19 10:00
**主题**: 允许抛出渲染给支持 EGL 的自定义渲染器，实现 GPU 加速渲染管线

---

## 目标
1. 设计 EGL 自定义渲染器插件接口（vtable 回调机制）
2. 实现 EGL/GLES2 渲染器后端
3. 更新渲染器桥接层支持自定义渲染器插件
4. 暴露 Canvas/WebGL 风格 JS API 到渲染器
5. 保持无 EGL 环境下的完全兼容

## 完成内容

### 1. 新建 `src/lr_renderer_egl.h` — EGL 渲染器接口 (~150 行)
- **`LR_CustomRenderer`** vtable 插件接口（定义在 `lr_renderer.h`，转发声明在此）
  - 生命周期: `init`, `destroy`
  - 帧管理: `begin_frame`, `end_frame`, `present`
  - 视口: `resize`, `set_viewport`, `clear`
  - 2D 绘制: `draw_rect`, `draw_text`, `draw_image`
  - 路径/形状: `begin_path`, `move_to`, `line_to`, `arc`, `fill`, `stroke`
  - 变换: `save`, `restore`, `translate`, `scale`, `rotate`
  - 像素回读: `read_pixels`
  - WebGL 直通: `get_native_gl`
- **`LR_EGLRenderer`** 结构体（EGL/GLES2 具体实现）
  - EGL 状态: display, surface, context, config
  - 离屏渲染: pbuffer surface
  - GLES 着色器: program_2d, VBO, attribute/uniform 位置
  - 像素回读缓冲区
  - 变换堆栈（8 级深度）
- EGL 可选编译: `-DLR_HAS_EGL` 启用，否则所有函数为 `static inline` 空桩
- 桩类型: `EGLDisplay`, `EGLSurface`, `EGLContext`, `EGLConfig`, `GLuint`, `GLenum` 等类型在无 EGL 时定义为 `void*`

### 2. 新建 `src/lr_renderer_egl.c` — EGL 渲染器实现 (~400 行)
- 仅在 `LR_EGL_AVAILABLE` 时编译
- **GLES2 着色器**:
  - 顶点着色器: 2D 位置 + 投影矩阵
  - 片段着色器: 纯色填充
- **EGL 初始化流程**:
  - `eglGetDisplay` → `eglInitialize` → `eglChooseConfig` (RGBA8)
  - 离屏: `eglCreatePbufferSurface`
  - 窗口: `eglCreateWindowSurface` (需 native_window)
  - `eglCreateContext` (GLES2) → `eglMakeCurrent`
- **绘制回调**:
  - `egl_cb_draw_rect`: 正交投影 + VBO 三角形绘制
  - `egl_cb_clear`: `glClearColor` + `glClear`
  - `egl_cb_begin_frame`: 清屏 + 视口设置
  - `egl_cb_present`: `eglSwapBuffers`
  - `egl_cb_save/restore`: 变换堆栈 push/pop
  - `egl_cb_get_native_gl`: 返回 EGLContext 句柄
- 静态 vtable `g_egl_vtable` 预填充所有回调
- `lr_egl_renderer_get_interface()`: 返回带 user_data 的 vtable 副本

### 3. 更新 `src/lr_renderer.h` — 渲染器桥接层扩展
- 新增渲染器类型: `LR_RENDERER_EGL` (6), `LR_RENDERER_PLUGIN` (7)
- `LR_CustomRenderer` 结构体完整定义（vtable 接口）
- `LR_RendererBridge` 新增字段:
  - `LR_CustomRenderer custom_renderer`
  - `int custom_renderer_active`
- 新增 API:
  - `lr_renderer_set_custom_renderer(rb, renderer)` — 设置/替换自定义渲染器
  - `lr_renderer_get_custom_renderer(rb)` — 获取当前自定义渲染器
  - `lr_renderer_init_egl(rb, w, h, offscreen, native_dpy, native_win)` — 一键初始化 EGL
  - `lr_renderer_begin_frame(rb)` / `lr_renderer_end_frame(rb)` / `lr_renderer_present(rb)` — 帧生命周期
  - `lr_renderer_clear(rb, r, g, b, a)` — 清屏（自动回退到内部帧缓冲）
  - `lr_renderer_draw_rect(rb, x, y, w, h, r, g, b, a)` — 绘制矩形（自动回退）
  - `lr_renderer_read_pixels(rb, out, x, y, w, h)` — 像素回读（自动回退）
  - `lr_renderer_get_native_gl(rb)` — 获取原生 GL 上下文

### 4. 更新 `src/lr_renderer.c` — 渲染器桥接实现
- `lr_renderer_create`: 初始化 `custom_renderer_active = 0`
- `lr_renderer_destroy`: 清理自定义渲染器（调用 `destroy` 回调）
- 所有新 API 实现:
  - 自定义渲染器活跃时 → 委派给 vtable
  - 自定义渲染器不活跃时 → 回退到内部帧缓冲（纯 CPU 像素操作）
  - `lr_renderer_init_egl`: 创建 EGL 渲染器，获取 vtable，设置到桥接

### 5. 新建 `src/lr_canvas.c` — Canvas JS API (~370 行)
- **`Canvas` 构造函数**: `new Canvas(300, 150)` 默认尺寸
- **`canvas.getContext('2d')`**:
  - 返回 `CanvasRenderingContext2D` 对象
  - 方法: `clearRect(x, y, w, h)`, `fillRect(x, y, w, h)`, `getImageData(x, y, w, h)`

## 架构设计

```
┌─────────────────────────────────────────────────────────┐
│                    JavaScript Layer                     │
│  new Canvas() → getContext('2d') / getContext('webgl') │
└───────────────────────┬─────────────────────────────────┘
                        │
┌───────────────────────┴─────────────────────────────────┐
│              lr_canvas.c (Canvas API)                   │
│  fillRect() → lr_renderer_draw_rect()                  │
│  getImageData() → lr_renderer_read_pixels()            │
└───────────────────────┬─────────────────────────────────┘
                        │
┌───────────────────────┴─────────────────────────────────┐
│           lr_renderer.c (Renderer Bridge)               │
│  ┌──────────────────────────────────────────────────┐  │
│  │  custom_renderer_active?                         │  │
│  │  YES → delegate to LR_CustomRenderer vtable      │  │
│  │  NO  → fallback to internal framebuffer (CPU)    │  │
│  └──────────────────────────────────────────────────┘  │
└───────┬───────────────────────────────┬─────────────────┘
        │                               │
        ▼                               ▼
┌───────────────────┐    ┌──────────────────────────────┐
│  Internal FB      │    │  LR_CustomRenderer Plugin    │
│  (CPU pixels)     │    │  ┌────────────────────────┐  │
│  PPM output       │    │  │ LR_EGLRenderer (EGL)   │  │
│                   │    │  │  • GLES2 shaders       │  │
│                   │    │  │  • pbuffer / window    │  │
│                   │    │  │  • GPU accelerated     │  │
│                   │    │  └────────────────────────┘  │
│                   │    │  ┌────────────────────────┐  │
│                   │    │  │ User Custom Renderer   │  │
│                   │    │  │  (Vulkan, Metal, etc.) │  │
│                   │    │  └────────────────────────┘  │
└───────────────────┘    └──────────────────────────────┘
```

## 关键设计决策
1. **EGL 可选**: 无 EGL 环境下所有桩函数编译为 `static inline` 空实现，不影响链接
2. **自动回退**: 所有绘制 API 在无自定义渲染器时自动回退到内部 CPU 帧缓冲
3. **插件架构**: `LR_CustomRenderer` vtable 允许用户提供任意渲染后端（Vulkan, Metal, DirectX 等）
4. **WebGL 直通**: `get_native_gl()` 返回原生 GLES 上下文句柄，允许 JS WebGL 代码直接操作 GPU
