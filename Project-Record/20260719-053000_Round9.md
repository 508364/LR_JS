# Round 9 - Windows 兼容层 (Win7+)

**时间**: 2026-07-19 05:30
**主题**: 跨平台兼容 —— 支持 Windows 7+ 到 Linux/macOS

---

## 目标
为 LR_JS 创建完整的跨平台兼容层，使其能在 Windows 7+ 上编译运行，同时保持 Linux/macOS 兼容。

## 完成内容

### 1. 新建 `src/lr_platform.h` — 跨平台兼容层核心
- 平台检测宏：`LR_PLATFORM_WINDOWS`、`LR_PLATFORM_LINUX`、`LR_PLATFORM_MACOS`
- Windows 头文件引入（`windows.h`, `winsock2.h`, `ws2tcpip.h`）
- POSIX 到 Windows 映射：
  - 文件操作：`lr_open`, `lr_close`, `lr_read`, `lr_write`, `lr_lseek`, `lr_ftruncate`, `lr_fstat`, `lr_stat`, `lr_unlink`, `lr_access`
  - Socket 操作：`lr_socket_close`, `lr_socket_errno`, `lr_socket_eagain`, `lr_socket_einprog`
  - 进程/线程：`lr_getpid`, `lr_sleep_ms`
- 时间 API：`lr_get_time_us()` — Windows 用 `QueryPerformanceCounter`，Linux/macOS 用 `gettimeofday`
- 内存信息：`lr_get_page_size()`, `lr_get_avail_mem_pages()`
- 共享内存映射：`LR_SHM_INVALID`, `LR_MMAP_FAILED`
- Socket 初始化：`lr_socket_init()`, `lr_socket_cleanup()`
- 动态库加载：`lr_dlopen`, `lr_dlsym`, `lr_dlclose`, `lr_dlerror`
- 非阻塞 socket：`lr_socket_set_nonblock()`
- 随机数：`lr_random_bytes()` — Windows 用 `CryptGenRandom`，Linux 用 `/dev/urandom`
- 线程局部存储：`LR_THREAD_LOCAL`
- 原子操作：`lr_atomic_add()`, `lr_atomic_load()`

## 技术要点
- 所有平台特定代码集中在 `lr_platform.h`，各源文件只需 `#include "lr_platform.h"`
- 使用 `static __inline` 函数而非宏，保证类型安全
- Windows 最小支持版本：`_WIN32_WINNT = 0x0601` (Windows 7)

## 已确认的遗留问题
- **QuickJS 引擎依赖**：项目通过 `ENGINE_DIR = ../quickjs` 直接引用外部 QuickJS 源码（`quickjs.c`, `libregexp.c`, `libunicode.c`, `cutils.c`, `quickjs-libc.c`, `dtoa.c`），这些文件在 `/workspace/quickjs/` 目录下。LR_JS 的 `src/` 层是自实现的，但 JS 引擎核心不是。
