## 项目概述

L/R_JS 是一个基于 QuickJS 引擎的纯 C 语言实现的全功能轻量级浏览器 JavaScript 运行器，目标支持 ES2022 特性。

## 技术选型

- **引擎**: QuickJS (Fabrice Bellard)，纯 C 实现，支持 ES2020+
- **语言**: 纯 C
- **构建**: Makefile + GCC
- **放弃的引擎**: V8 (C++ 实现，不符合纯 C 要求)

## 关键技术问题与解决方案

### 1. GC 断言失败 (list_empty(&rt->gc_obj_list))

**问题**: QuickJS 在释放 Runtime 时检查 gc_obj_list 必须为空，但多个模块触发此断言失败。

**根因分析**:
- `JS_SetConstructor` 创建引用循环 (constructor ↔ prototype)
- 当 prototype 是普通对象（无 finalizer）时，不在 gc_obj_list 中
- GC 无法打破此循环，导致 C function 对象（在 gc_obj_list 中）无法被释放

**解决方案**: 不使用 `JS_SetConstructor`，改用直接设置 prototype 属性：
```c
JS_SetPropertyStr(ctx, ctor, "prototype", JS_DupValue(ctx, proto));
JS_FreeValue(ctx, proto);
```
避免引用循环，无 GC 问题。

### 2. JS_CFUNC_constructor 中 this 值的处理

**问题**: `new` 调用构造函数时返回 `undefined`。

**根因**: QuickJS 的 `JS_CFUNC_constructor` 将 `new_target` 作为第2参数传给 C 函数，而非 `this`。C 函数必须自行创建对象并返回。

**解决方案**: 构造函数中从 `new_target.prototype` 获取原型，用 `JS_NewObjectProto` 创建正确原型链的对象：
```c
JSValue proto = JS_GetPropertyStr(ctx, new_target, "prototype");
JSValue obj = JS_NewObjectProto(ctx, proto);
JS_FreeValue(ctx, proto);
```

### 3. JS_GetArrayBuffer 不支持 TypedArray

**问题**: `JS_GetArrayBuffer` 只接受 `ArrayBuffer`，不接受 `Uint8Array` 等 TypedArray。

**解决方案**: 先用 `JS_GetTypedArrayBuffer` 获取底层 ArrayBuffer，再用 `JS_GetArrayBuffer`：
```c
JSValue abuf = JS_GetTypedArrayBuffer(ctx, argv[0], &offset, &length, &bytes_per_elem);
uint8_t *buf = JS_GetArrayBuffer(ctx, &buf_len, abuf);
JS_FreeValue(ctx, abuf);
```

### 4. QuickJS 引用计数规则

- `JS_SetPropertyStr` 内部使用 `set_value`（不 DupValue），调用方不应再 FreeValue
- `JS_SetConstructor` 内部会 DupValue，调用方需要 FreeValue 本地引用
- `JS_SetPropertyFunctionList` 的 `JS_CFUNC_DEF` 条目是惰性创建的（通过 `JS_DefineAutoInitProperty`）

### 5. 编译问题

- `environ` 和 `sighandler_t` 需要 `-D_GNU_SOURCE`
- `TRUE` 宏需要 `#include "cutils.h"`
- 链接需要 `-ldl`

## ES2022 特性支持

QuickJS 引擎原生支持大部分 ES2022 特性，包括：
- `Array.at()` / `String.at()`
- `Object.hasOwn()`
- 类字段和私有字段/方法
- `Error.cause`
- Top-level await
- WeakRef / FinalizationRegistry

## 运行方式

```bash
# 编译
cd /workspace/LR_JS && make

# 运行脚本
./build/lr_js examples/hello.js

# 执行表达式
./build/lr_js -e "console.log('Hello, L/R_JS!')"

# 模块模式
./build/lr_js -m script.mjs

# 交互式 REPL
./build/lr_js -i
```
